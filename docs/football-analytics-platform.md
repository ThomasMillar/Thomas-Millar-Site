# Football Analytics Platform

## Overview

A football analytics project combining API data ingestion, SQL analysis and Power BI dashboards to explore Premier League performance.

The project focuses on transforming raw football data into structured datasets and meaningful insights.

## Objectives

* Collect football data from APIs
* Store structured datasets
* Analyse player and team performance
* Create interactive reporting dashboards

## Tech Stack

* Python
* SQL
* Azure SQL
* Power BI
* APIs

## Data Workflow

The platform follows this workflow:

1. **Data Source**

   * Football APIs providing player, team and league statistics

2. **Data Ingestion**

   * Python scripts collect and process external API data

3. **Database Layer**

   * Azure SQL stores structured datasets for analysis

4. **Reporting Layer**

   * Power BI connects to the database to create interactive dashboards

5. **Analytics**

   * Explore team performance, player statistics and league trends

## Key Features

### Data Ingestion

Automated collection of football statistics from external APIs.

### Data Modelling

Created SQL tables designed for analytical reporting and dashboard performance.

### Dashboard Development

Built Power BI reports exploring:

* Team performance
* Player statistics
* League trends
* Performance comparisons
