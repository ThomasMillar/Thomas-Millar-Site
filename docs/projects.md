# Projects

A collection of data analytics and data platform projects showcasing my experience with SQL, Python, dashboards and data workflows.

---

## 🏠 UK Housing Data Platform

A data analytics platform exploring UK property trends using HM Land Registry Price Paid Data.

The project focuses on transforming raw housing data into structured datasets for analysis and visualisation.

### Technologies

- Python
- PostgreSQL
- Docker
- FastAPI
- Streamlit

### Workflow

Raw housing data  
→ Python processing  
→ PostgreSQL database  
→ API layer  
→ Interactive dashboard
